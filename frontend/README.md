# Донор-помощник — frontend

React + Vite. Разделы: «Главная», «Информация», «Предложения», плюс страницы центра и мероприятия.

## Запуск

1. Запустите backend по инструкции из корневого `README.md` (по умолчанию `http://127.0.0.1:8000`).
2. Запустите frontend:

```bash
cd frontend
npm install
cp .env.example .env   # VITE_API_URL — адрес backend
npm run dev            # http://localhost:5173 — этот адрес уже разрешён в CORS backend
npm test               # тесты расчёта интервалов и миграции хранилища
npm run build          # сборка в dist/
```

## Какие маршруты API используются

Только публичные GET, без `X-Admin-Key`:

| Маршрут | Где |
|---|---|
| `GET /api/donation-intervals/matrix` | Главная: расчёт ориентировочной даты следующей донации |
| `GET /api/rules` | Информация: памятки, сгруппированные по `category` |
| `GET /api/events`, `GET /api/events/{id}` | Предложения, страница мероприятия, уведомления на главной |
| `GET /api/centers`, `GET /api/centers/{id}` | Предложения, страница центра |

## Что где хранится

| Данные | Где |
|---|---|
| Дневник донаций (дата, код вида, объём) | `localStorage`, ключ `donor-pomoshnik:diary`. На сервер не отправляется |
| Прочитанные уведомления | там же |
| Последняя загруженная матрица интервалов | `localStorage`, ключ `donor-pomoshnik:matrix-cache` — чтобы расчёт работал без сети |
| Центры, мероприятия, памятки, матрица | приходят с backend |

Интервалы в коде не хранятся. Если матрицы нет ни с сервера, ни в кеше, главная показывает «Расчёт временно недоступен».
Записи из первой версии фронта (ключ `donor-pomoshnik:v1`, коды `blood` и т. п.) автоматически переносятся в новый формат.

## Структура

```
src/
  config.js              адрес API (VITE_API_URL) и часовой пояс
  lib/api.js             все запросы к backend, обработка ошибок
  lib/rules.js           чистые функции расчёта по матрице (тесты: rules.test.js)
  lib/storage.js         слой localStorage, миграция и защита от битых данных
  lib/useMatrix.js       матрица с backend + кеш
  lib/useDonorStore.js   дневник донаций
  lib/notifications.js   лента уведомлений (внутри сайта, не push)
  pages/                 Home, Info, Offers, EventDetails, CenterDetails
```

## Вопросы к команде

- Фильтры «В вузах / Акции» из макета убраны: в `EventResponse` нет поля для них. Нужно поле `category` у мероприятия?
- Часов работы центра в API нет — колонка из макета убрана.
- Блок «Статистика учащихся Москвы» убран: без данных с сервера его не посчитать.
- База должна быть наполнена через Swagger: центры, мероприятия, памятки (`/api/rules`) и матрица интервалов. Для частых вопросов используйте категорию со словом «вопрос» — она показывается аккордеоном.

## PWA

- `public/manifest.webmanifest` и иконки в `public/icons/` — сайт можно установить на телефон.
- `public/sw.js` — service worker: без интернета открывается сайт и показываются последние загруженные мероприятия, центры и памятки. Кешируются только GET-запросы; личный дневник в сеть не уходит и в кеш SW не попадает.
- Регистрируется только в собранной версии. Проверить локально: `npm run build && npm run preview`, затем в DevTools → Application → Service Workers.
- Баннер «Установите приложение» на главной: в Chrome/Android — кнопка установки, на iPhone — подсказка «Поделиться → На экран „Домой“».
- Для работы на телефоне сайт должен открываться по HTTPS (на localhost — можно без него).
- После изменения логики `sw.js` увеличьте в нём `VERSION`.
