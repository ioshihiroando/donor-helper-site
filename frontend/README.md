# Донор-помощник — фронтенд

React + Vite. Три раздела: «Информация», «Предложения», «Главная».

## Запуск

```bash
npm install
cp .env.example .env   # указать адрес бэкенда в VITE_API_URL
npm run dev            # http://localhost:5173
npm test               # тесты расчёта интервалов
npm run build          # сборка в dist/ для GitHub Pages
```

Если `VITE_API_URL` пустой или бэкенд не отвечает, «Предложения» показывают демо-данные с пометкой.

## Как устроено

| Файл | Что делает |
|---|---|
| `src/lib/rules.js` | Таблица интервалов из приказа Минздрава № 215н (прил. 7) и расчёт даты следующей сдачи |
| `src/lib/storage.js` | Хранение сдач в `localStorage`. На сервер ничего не уходит |
| `src/lib/useDonorStore.js` | Хук: список сдач, добавление, удаление, прочитанные уведомления |
| `src/lib/api.js` | `GET /api/events`, `GET /api/centers` и адаптеры полей |
| `src/lib/notifications.js` | Лента уведомлений собирается на фронте (не push) |
| `src/data/info.js` | Тексты раздела «Информация» и частые вопросы |
| `src/config.js` | Флаг блока «Статистика учащихся Москвы» (выключен) |

Навигация через hash (`#/home`, `#/info`, `#/offers`), поэтому на GitHub Pages не будет 404 при обновлении страницы.

## Важно

- **Ключ администратора во фронт не класть.** Всё из сборки и `.env` фронта видно в браузере. Фронт только читает данные через GET.
- Расчёт срока берёт самое строгое ограничение по всем прошлым сдачам, а не только по последней.
- Лимит «5 раз в год для мужчин, 4 для женщин» не считается: для него нужен пол, а профиля нет.
