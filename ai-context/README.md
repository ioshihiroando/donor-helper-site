# Контекст для ИИ-помощников проекта «Донор-напарник»

Эти документы предназначены для отдельных ИИ-помощников команды. Перед началом работы передайте помощнику:

1. `AGENTS.md` — обязательно, это общий контекст и правила проекта.
2. Один профиль роли: `FRONTEND_AI.md`, `QA_AI.md` или `DEVOPS_AI.md`.
3. При необходимости — актуальные исходники соответствующей части проекта.

## Как использовать

- **Frontend-разработчик:** `AGENTS.md` + `FRONTEND_AI.md`.
- **Тестировщик:** `AGENTS.md` + `QA_AI.md`.
- **DevOps:** `AGENTS.md` + `DEVOPS_AI.md`.
- **Тимлид:** `AGENTS.md` + `TEAM_LEAD_AI.md`.

Файлы описывают согласованные решения на момент подготовки. Если код, Swagger/OpenAPI или более позднее решение руководителя команды им противоречат, сначала сообщите о расхождении. Не исправляйте архитектуру молча.
